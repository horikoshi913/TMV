# 北海道在来線路線図（TMV）

Google Maps JavaScript API を使った Web アプリです。北海道の地図上に、JR北海道の全在来線、道南いさりび鉄道、札幌市営地下鉄、札幌市電・函館市電の路線・全駅を表示します。

- 17 路線・417 駅（乗換駅は統合済み）
- サイドバーに路線ごとの駅一覧（実際の駅順）。路線の表示／非表示の切り替え、クリックで路線にフォーカス
- 駅をクリックすると所属路線と前後の駅を表示。駅名検索に対応
- 一定以上ズームすると駅名を自動表示。スマートフォンにも対応
- 走行中の列車を表示。函館本線は**時刻表どおり**、それ以外は**デモ用の仮想列車**。10 秒ごとに更新
- Google Maps API キーがなくても使える**オフライン地図**モード（海岸線＋路線の簡易地図、外部通信なし）

## 走行中の列車

### 函館本線（時刻表）

`data/trains.json`（自作の時刻表データ）にある列車を、時刻表どおりに走らせます。停車駅の間は線路網上の最短経路を一定の速さで走るものとして位置を計算するため、函館本線から他の路線へ直通する列車（特急北斗・オホーツク・宗谷、木古内行きなど）もそのまま表示されます。遅れや運休は反映されません。地図上では濃い縁取り、情報ウィンドウでは「時刻表」と表示します。

形式は列車ごとに `train_id`・`train_type`・`bound_for`・`direction`・`schedule`（`station_name`・`arrival_time`・`departure_time`、`HH:MM:SS`）です。駅名の「森(北海道)」「札幌(ＪＲ)」のような括弧書きや「ケ／ヶ」の違いは自動で合わせます。路線データにない駅を含む列車は表示せず、ブラウザのコンソールに警告を出します。
時刻表で走らせる路線は `js/app.js` の `TIMETABLE_LINES` で指定します（その路線のデモ列車は出しません）。

### その他の路線（デモ）

JR北海道は列車の走行位置を取得できる API を公開していないため、ここで表示しているのは仮想の列車です。`js/trains.js` の `SERVICES` に定めた一定間隔のダイヤ（6:00〜22:00 発）から現在の日本時間における位置を計算し、実際の線形に沿って走らせています。実際の運行とは関係なく、画面上にも「デモ」と表示しています。
`SERVICES`（区間・運転間隔・種別）と `TYPES`（速度・停車時間）を変更すれば調整できます。

## Docker で起動（推奨）

1. 環境変数ファイルをコピーし、Google Maps API キーを記入します。

   ```bash
   cp .env.example .env
   ```

2. ビルドして起動します。

   ```bash
   docker compose up -d --build
   ```

3. ブラウザで http://localhost:8000 を開きます。停止するときは `docker compose down` を実行します。

コンテナ起動時に環境変数 `GOOGLE_MAPS_API_KEY`（と任意の `GOOGLE_MAPS_MAP_ID`）から `config.js` を生成するため、API キーはイメージに含まれません。
ポートを変更する場合は `compose.yaml` の `8000:80` を書き換えてください。

## Docker を使わずに起動

1. Google Cloud Console で **Maps JavaScript API** を有効にし、API キーを作成します（HTTP リファラー制限の設定を推奨）。
2. 設定ファイルをコピーし、API キーを記入します。

   ```bash
   cp config.example.js config.js
   ```

3. 任意の静的サーバーで起動します（`file://` で直接開くとデータを読み込めません）。

   ```bash
   python3 -m http.server 8000
   ```

4. ブラウザで http://localhost:8000 を開きます。

`config.js` がない場合は画面で API キーの入力を求められます（ブラウザの localStorage に保存）。`?key=...` パラメータで一時的に指定することもできます。
`mapId` を設定しない場合は Google 提供の開発用 `DEMO_MAP_ID` を使います。本番利用では Cloud Console でマップ ID を作成してください。

## オフライン地図（API キー不要）

Google Maps API キーがないときや、インターネットに接続できないときに使える簡易地図です。海岸線と路線・駅・列車を自前で描画するため、外部への通信は一切ありません（駅検索、路線の表示切り替え・フォーカス、列車表示などの機能は Google マップ版と同じ）。

- API キー入力画面の「API キーなしで使う（オフライン地図）」を押すと切り替わります。選択はブラウザに保存され、次回からもオフライン地図で開きます。
- URL に `?offline=1` を付けても開けます（`?offline=0` で Google マップを強制）。
- `config.js` に `offline: true` を書くと、常にオフライン地図で起動します。
- Google マップの読み込みに失敗した場合（ネットワーク未接続など）は、自動的にオフライン地図に切り替わります。
- 地図右上の「Google マップで表示」で Google マップ版に戻せます。

操作：ドラッグで移動、マウスホイール／ピンチ／＋−ボタン／ダブルクリックで拡大縮小。

## データ

`data/hokkaido-rail.json` は、国土交通省「国土数値情報（鉄道データ）N02-25」から `scripts/build_data.py` で生成しています。

```bash
curl -O https://nlftp.mlit.go.jp/ksj/gml/data/N02/N02-25/N02-25_GML.zip
unzip N02-25_GML.zip
python3 scripts/build_data.py N02-25_GML/UTF-8
```

スクリプトは線分の結合、座標の簡略化、経由駅からの駅順計算、乗換駅の統合を行います。路線や区間を増減するには、スクリプト冒頭の `LINES` を変更してください（N02 の路線名が複数に分かれている路面電車は、路線名をまとめて指定できます。起点と終点が同じ区間はループ線として扱います）。

出典：「国土数値情報（鉄道データ）」（国土交通省）を加工して作成

オフライン地図の海岸線 `data/hokkaido-land.json` は、[Natural Earth](https://www.naturalearthdata.com/)（1:10m Land、パブリックドメイン）から `scripts/build_coast.py` で北海道周辺を切り出して生成しています（外部ライブラリ不要）。

```bash
curl -LO https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_land.geojson
python3 scripts/build_coast.py ne_10m_land.geojson
```
