# 北海道在来線路線図（TMV）

Google Maps JavaScript API を使った Web アプリです。北海道の地図上に、JR北海道の全在来線と道南いさりび鉄道の路線・全駅を表示します。

- 12 路線・322 駅（乗換駅は統合済み）
- サイドバーに路線ごとの駅一覧（実際の駅順）。路線の表示／非表示の切り替え、クリックで路線にフォーカス
- 駅をクリックすると所属路線と前後の駅を表示。駅名検索に対応
- 一定以上ズームすると駅名を自動表示。スマートフォンにも対応
- 走行中の列車を表示（**デモ用の仮想列車**）。10 秒ごとに更新

## 走行中の列車（デモ）

JR北海道は列車の走行位置を取得できる API を公開していないため、ここで表示しているのは仮想の列車です。`js/trains.js` の `SERVICES` に定めた一定間隔のダイヤ（6:00〜22:00 発）から現在の日本時間における位置を計算し、実際の線形に沿って走らせています。実際の運行とは関係なく、画面上にも「デモ」と表示しています。
`SERVICES`（区間・運転間隔・種別）と `TYPES`（速度・停車時間）を変更すれば調整できます。

## Docker で起動（推奨）

1. 環境変数ファイルをコピーし、Google Maps API キーを記入します。

   ```bash
   cp .env.example .env
   ```

2. ビルドして起動します。

   ```bash
   docker compose up -d --build
   ```

3. ブラウザで http://localhost:8000 を開きます。停止するときは `docker compose down` を実行します。

コンテナ起動時に環境変数 `GOOGLE_MAPS_API_KEY`（と任意の `GOOGLE_MAPS_MAP_ID`）から `config.js` を生成するため、API キーはイメージに含まれません。
ポートを変更する場合は `compose.yaml` の `8000:80` を書き換えてください。

## Docker を使わずに起動

1. Google Cloud Console で **Maps JavaScript API** を有効にし、API キーを作成します（HTTP リファラー制限の設定を推奨）。
2. 設定ファイルをコピーし、API キーを記入します。

   ```bash
   cp config.example.js config.js
   ```

3. 任意の静的サーバーで起動します（`file://` で直接開くとデータを読み込めません）。

   ```bash
   python3 -m http.server 8000
   ```

4. ブラウザで http://localhost:8000 を開きます。

`config.js` がない場合は画面で API キーの入力を求められます（ブラウザの localStorage に保存）。`?key=...` パラメータで一時的に指定することもできます。
`mapId` を設定しない場合は Google 提供の開発用 `DEMO_MAP_ID` を使います。本番利用では Cloud Console でマップ ID を作成してください。

## データ

`data/hokkaido-rail.json` は、国土交通省「国土数値情報（鉄道データ）N02-25」から `scripts/build_data.py` で生成しています。

```bash
curl -O https://nlftp.mlit.go.jp/ksj/gml/data/N02/N02-25/N02-25_GML.zip
unzip N02-25_GML.zip
python3 scripts/build_data.py N02-25_GML/UTF-8
```

スクリプトは線分の結合、座標の簡略化、経由駅からの駅順計算、乗換駅の統合を行います。路線や区間を増減するには、スクリプト冒頭の `LINES` を変更してください。

出典：「国土数値情報（鉄道データ）」（国土交通省）を加工して作成
